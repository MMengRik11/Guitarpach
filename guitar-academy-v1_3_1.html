Cara Stem yang Benar
1
Izinkan akses mikrofon
Browser akan meminta izin mikrofon saat pertama kali. Klik "Allow" / "Izinkan". Data audio tidak dikirim ke mana pun — diproses langsung di browser.
2
Pilih senar target, lalu petik
Pilih senar yang ingin distem (misal E₂), lalu petik senar 6 gitar. Jarum dan nada yang terdeteksi akan muncul real-time.
3
Sesuaikan sampai jarum di tengah (hijau)
Jarum ke kiri = terlalu rendah → kencangkan. Jarum ke kanan = terlalu tinggi → kendurkan. In tune jika ±5 cents dari pusat.
4
Longgarkan dulu, baru naikkan
Selalu approach pitch dari bawah. Jika terlalu tinggi, turunkan sedikit melewati target, lalu naikkan kembali ke in tune.

🎸 FRETBOARD — 6 Senar · 12 Fret
CAGED System
CAGED = 5 posisi chord (C, A, G, E, D shape) yang mencakup seluruh fretboard. Setiap posisi punya pola skala yang menyertainya. Menguasai CAGED = bisa bermain di semua kunci di semua posisi fretboard.
Hafal Nada di Fretboard
Mulai hafalkan nada di senar 6 (E: F, F#, G, G#, A, A#, B, C...) dan senar 5 (A: A#, B, C, C#, D...). Nada di senar 1 sama persis dengan senar 6. Gunakan dot marker di fret 3, 5, 7, 9, dan 12.

❓ Pertanyaan Umum
Apakah API key saya aman?
Ya. Key disimpan hanya di browser kamu (localStorage) dan dikirim langsung ke server provider. Tidak melewati server GuitarPath.
Berapa biaya pemakaian Groq?
Groq 100% gratis untuk model Llama dan Mixtral. Tidak perlu kartu kredit sama sekali.
Kenapa muncul error saat test koneksi?
Pastikan: (1) API key sudah di-copy dengan lengkap, (2) provider yang dipilih sesuai dengan key, (3) koneksi internet aktif.
Bisakah ganti provider kapan saja?
Bisa. Tinggal pilih provider lain → input key baru → test koneksi. Key lama tidak terhapus otomatis.
